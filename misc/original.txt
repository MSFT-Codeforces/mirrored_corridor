**Problem Statement**
Vasya is reading an e-book that contains `n` pages numbered from `1` to `n`. The screen currently shows page `x`, and Vasya wants to get to page `y`.

The e-book has two buttons:
- one scrolls **forward** by `d` pages,
- the other scrolls **backward** by `d` pages.

Vasya is not allowed to scroll outside the book. If pressing a button would move past page `1` or past page `n`, the page becomes `1` or `n` respectively (i.e., it is clamped to the nearest boundary).

For example, if `n = 10` and `d = 3`:
- from page `1` you can go to page `1` (backward) or `4` (forward),
- from page `2` you can go to page `1` or `5`,
- from page `6` you can go to page `3` or `9`,
- from page `8` you can go to page `5` or `10`.

For each test case, compute the minimum number of button presses needed to reach page `y` starting from page `x`, or output `-1` if it is impossible.

**Input Format**
The first line contains an integer `t` (`1 ≤ t ≤ 10^3`) — the number of test cases.

Each of the next `t` lines contains four integers `n, x, y, d`
(`1 ≤ n, d ≤ 10^9`, `1 ≤ x, y ≤ n`) — the number of pages, the current page, the desired page, and the scroll distance per button press.

**Output Format**
For each test case print one integer:
- the minimum number of button presses to reach `y` from `x`, or
- `-1` if it cannot be done.

**Examples**
Input:
```
3
10 4 5 2
5 1 3 4
20 4 19 3
```

Output:
```
4
-1
5
```

Explanation:
- Test 1: one optimal sequence is `4 → 2 → 1 → 3 → 5`.
- Test 2: from page `1` it is only possible to reach pages `1` and `5`.
- Test 3: one optimal sequence is `4 → 7 → 10 → 13 → 16 → 19`.

**Editorial**
Let `INF` be a very large number.

It turns out the optimal answer always belongs to one of these three options:

1) **Go directly from `x` to `y` without using pages `1` or `n`.**  
This is possible iff `|x - y|` is divisible by `d`.  
Then the number of presses is:
- `|x - y| / d`.

2) **First go to page `1`, then to `y`.**  
Reaching page `1` from `x` takes:
- `ceil((x - 1) / d)` presses, because each backward press decreases the page by `d`, and the last press may clamp to `1`.

From page `1` to `y` is possible iff `(y - 1)` is divisible by `d`, and then it takes:
- `(y - 1) / d` presses.

So this route is valid when `(y - 1) % d == 0`, with total:
- `ceil((x - 1) / d) + (y - 1) / d`.

3) **First go to page `n`, then to `y`.**  
Similarly:
- to reach `n` from `x`: `ceil((n - x) / d)`,
- from `n` to `y` is possible iff `(n - y) % d == 0`, taking `(n - y) / d`.

Total (when valid):
- `ceil((n - x) / d) + (n - y) / d`.

Compute the minimum among all valid options; if none are valid, print `-1`.

Time complexity is `O(t)`.

**Code**
```cpp
#include <bits/stdc++.h>
using namespace std;

static const long long INF = (long long)4e18;

long long directSteps(long long a, long long b, long long d) {
    long long diff = llabs(a - b);
    if (diff % d != 0) return INF;
    return diff / d;
}

long long ceilStepsToBoundary(long long dist, long long d) {
    // ceil(dist / d)
    return (dist + d - 1) / d;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;
    while (t--) {
        long long n, x, y, d;
        cin >> n >> x >> y >> d;

        long long ans = INF;

        // 1) Direct
        ans = min(ans, directSteps(x, y, d));

        // 2) Via page 1
        if ((y - 1) % d == 0) {
            long long to1 = ceilStepsToBoundary(x - 1, d);
            long long from1 = (y - 1) / d;
            ans = min(ans, to1 + from1);
        }

        // 3) Via page n
        if ((n - y) % d == 0) {
            long long ton = ceilStepsToBoundary(n - x, d);
            long long fromn = (n - y) / d;
            ans = min(ans, ton + fromn);
        }

        if (ans >= INF / 2) ans = -1;
        cout << ans << "\n";
    }
    return 0;
}
```
